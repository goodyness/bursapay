# Brand Ambassador & Referral Rewards Program

The **BursaPay Ambassador Program** empowers campus student leaders, tech advocates, and community creators to champion modern digital payments and earn automated commissions.

---

## 🎓 How the Program Works

```
1. Ambassador Registers ──► 2. Receives Custom Referral Link ──► 3. Onboards Orgs / Students
                                                                         │
                                                                         ▼
6. Automated Monthly Payout ◄── 5. Real-Time Commission Accrual ◄── 4. Transactions Processed
```

1. **Sign Up:** Qualified student leaders apply for ambassador status (`is_ambassador=True`).
2. **Unique Referral Code:** Each ambassador receives a dedicated tracking URL (e.g., `bursapay.com/?ref=AMB-UNILAG-01`).
3. **Onboarding:** Introduce academic faculties, departmental associations, event organizers, or campus vendors to BursaPay.
4. **Automated Commission:** When onboarded organizations collect dues or vendors settle bookings, the ambassador earns a transparent percentage of platform fees.
5. **Dashboard Analytics:** Track registered referrals, active transaction volumes, and accrued earnings in real time.
6. **Monthly Bank Payouts:** Direct settlement to the ambassador's bank account.
