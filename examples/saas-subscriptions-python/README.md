# Python SaaS Subscriptions Example

This example demonstrates how to manage recurring billing plans, subscribe customers, and process automated renewal webhooks using Flask and `bursapay-sdk`.

---

## Setup & Run

```bash
pip install -r requirements.txt

export BURSAPAY_SECRET_KEY=bp_sec_test_DEMO_KEY_HERE
export BURSAPAY_WEBHOOK_SECRET=sec_wh_DEMO_SECRET_HERE

python app.py
```
